**📌Objective**

This project analyzes Dmart sales data to track revenue performance, regional trends, customer segments, and product-level insights. The dashboard helps identify sales growth, discount impact, and category-wise performance.

**🛠 Tools Used**
- Power BI
- Power Query
  
📂 Dataset Description

  The dataset contains order-level sales information with the following fields:

- Category
- City
- Country
- Customer Name
- Discount
- Feedback
- Order Date
- Order ID
- Product Name
- Quantity
- Region
- Sales
- Segment
- Ship Mode
- State
- Sub Category
  
**📊 KPIs Created**
- Total Sales
- Total Orders
- Total Quantity
- Average Discount
- Sales Growth Trend

**📈 Visualizations**
- Sales by Category
- Sales by Region & Category
- Sales Trend Over Time
- Top 5 Products by Sales
- Sales by Segment
- Ship Mode Distribution
  
**📌 Key Insights**
- Identified highest performing product categories
- Analyzed regional sales contribution
- Measured impact of discount on sales
- Compared sales performance across customer segments

**✅ Conclusion**

The Dmart Sales Dashboard provides a clear overview of revenue performance and customer buying patterns. It supports data-driven business decisions for improving profitability and operational efficiency.
